
# 📚 Student Data Management System – C++ Project

Welcome to the **Student_Data** repository! 🎓  
This project is a simple yet powerful console-based **Student Data Management System** written in **C++**. It helps manage and display student records including name, ID, marks, and more.  

Built as a part of my programming practice, this project showcases basic file handling, structures, and object-oriented programming concepts in C++.

---

## 🚀 Features

- ➕ Add new student records
- 📋 Display all stored records
- 🔍 Search by student ID
- 🗃️ Store data using file handling
- 🔁 Looping for multiple operations
- 💡 Simple and beginner-friendly code

---

## 🧰 Technologies Used

| Tool        | Description                           |
|-------------|---------------------------------------|
| **C++**     | Core programming language              |
| **OOP**     | Classes & objects for modular design   |
| **File I/O**| Read/write records to local files      |
| **.exe Build** | Compiled executable for Windows    |
